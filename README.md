# Physical AI — 40-Lesson Curriculum (Version 1.0)

Established: 2026-10-13

This is the agreed initial roadmap, organized into eight modules of five lessons each. Lesson titles after Lesson 5 are provisional and can be refined as learning proceeds.

| Module | Lesson range | Focus |
| --- | --- | --- |
| 1\. Robotics Foundations | 1–5 | Physical AI, coordinate systems, orientation, pose, coordinate transformations |
| 2\. Robot Kinematics | 6–10 | Joints, forward/inverse kinematics, robot arms |
| 3\. Robot Dynamics & Control | 11–15 | Forces, torque, motion, PID control |
| 4\. Robot Perception | 16–20 | Cameras, depth, sensor fusion, object detection |
| 5\. Robotics Simulation | 21–25 | Isaac Sim, Isaac Lab, MuJoCo, ROS 2 |
| 6\. Robot Learning | 26–30 | Imitation learning, reinforcement learning, policies |
| 7\. Vision-Language-Action Models | 31–35 | VLA architectures, datasets, LeRobot, deployment |
| 8\. End-to-End Physical AI | 36–40 | Integrated robot projects, evaluation, research |

## Learning protocol

One small concept at a time; intuition, simple mathematics, interactive practice, feedback, simulator experiment where appropriate, then lesson manual (PDF), Markdown notes, code/tests and an honest evidence record before proceeding. Do not treat researched answers as independent mastery. Keep track of user-demonstrated versus user-reported versus tool-verified activity.
